EVS (Evaluación Visual del Suelo) es una aplicación móvil que permite a agricultores y agrónomos evaluar la salud del suelo usando métodos visuales estandarizados. La app guía al usuario a través de formularios estructurados para evaluar características como estructura, color, porosidad y compactación del suelo.

No, EVS funciona completamente offline. Puedes realizar evaluaciones en el campo sin conexión a internet. Los datos se sincronizan automáticamente cuando recuperas la conexión.

EVS está disponible para dispositivos Android 6.0 o superior. La aplicación está optimizada para funcionar en tablets y smartphones con pantallas de al menos 5 pulgadas para una mejor experiencia de usuario.

EVS utiliza el GPS de tu dispositivo para registrar automáticamente la ubicación exacta de cada evaluación. Esto te permite crear mapas de tus campos con datos históricos y comparar la evolución del suelo en diferentes áreas a lo largo del tiempo.

La evaluación visual del suelo es un método científicamente validado que, cuando se realiza correctamente, proporciona una excelente correlación con análisis de laboratorio para muchos parámetros. EVS incluye guías visuales detalladas y protocolos estandarizados para maximizar la precisión de las evaluaciones.

Para instalar el APK: 1) Descarga el archivo APK desde nuestro sitio web, 2) Ve a Configuración > Seguridad > Fuentes desconocidas y actívalo, 3) Abre el archivo APK descargado y sigue las instrucciones de instalación. Si tienes problemas, consulta nuestro video tutorial en la sección de ayuda.
